**Мониторинг эмоций в группах детского сада для безопасности — заметить неблагополучие до эскалации.**

Emotion-Guard следит за настроением в группе по сигналам эмоций на лицах (радость / спокойствие / грусть / гнев) детей и воспитателей, сводит их в живой дашборд и выдаёт ранние предупреждения — например, ребёнок скатывается в затяжное неблагополучие или у воспитателя всплеск стресса — чтобы персонал успел заботливо проверить ситуацию *до* того, как она превратится в инцидент.

> **Статус проекта: демо v0.1 (честная редакция).**
> Сквозной конвейер сегодня работает на **полностью синтетических данных**: фиктивные кадры, мок-классификатор эмоций с фиксированным сидом и сценарный сценарий группы. Никаких реальных детей, реальных изображений, реальных весов модели. Что реально: обвязка детекции лиц (OpenCV Haar), заменяемый интерфейс классификатора, правила оповещений и отчётность. ## Предыстория

Этот проект вырос из реальной работы: система распознавания эмоций, внедрённая в детских садах, определяла, счастливы ли дети (и воспитатели), помечая затяжное негативное настроение как ранний индикатор, чтобы помочь предотвратить жестокое обращение и насильственные инциденты. Emotion-Guard — это clean-room демо-пересборка той идеи: та же миссия, синтетические данные, готово для портфолио.

## Что делает

1. **Детекция** лиц на кадрах группы (каскад Хаара OpenCV; в демо — мок-детектор).
2. **Классификация** эмоций по лицам через заменяемый интерфейс `EmotionClassifier` (по умолчанию детерминированный мок с меткой SIMULATED).
3. **Агрегация** в сводки настроения по каждому ребёнку и по группе.
4. **Оповещения** по трём правилам:
   - `sustained_negative_mood` — ребёнок показывает грусть/гнев в большинстве последних наблюдений (по мере сохранения warning → critical);
   - `teacher_negative_spike` — воспитатель вспыхивает гневом/стрессом (сам по себе сигнал безопасности);
   - `sudden_mood_swing` — радость → гнев за минуты (флаг наблюдения).
5. **Отчёты** — консольный дашборд, `classroom_report.json` и одностраничный `report.html`.

## Быстрый старт

```bash
pip install -r requirements.txt

# Запуск симуляции учебного дня (8 детей + 1 воспитатель, сценарная история)
python examples/demo.py
# -> консольный дашборд + examples/output/classroom_report.json + report.html

# Запуск набора тестов
python -m pytest tests/ -q
```

Сюжет демо сценарный, чтобы каждое правило срабатывало наглядно: Child-04 днём скатывается в неблагополучие (critical), Teacher-01 однажды вспыхивает гневом (warning), Child-02 за 20 минут переходит от радости к гневу (watch).

## Подключение настоящей модели

`EmotionClassifier` — это протокол: реализуйте `classify(face_image) -> EmotionResult` и подключите. `classifier.FERClassifier` документирует путь интеграции (`fer` или `deepface`, с мэппингом 7 эмоций → 4 класса). На реальных результатах держите `simulated=False`, чтобы нижележащий код мог их отличить.

## Этика и приватность

- **В демо ноль реальных изображений детей.** Все кадры синтетические; все «люди» — сгенерированные ID.
- **Предполагаемое использование — строго opt-in**: внедрение в настоящем детском саду требует письменного согласия родителей, опубликованной политики хранения данных, локальной обработки (без загрузки лиц детей в облако) и человеческой проверки каждого оповещения — система *предлагает проверки*, но никогда не принимает дисциплинарных решений.
- У ИИ эмоций есть известные ограничения точности и предвзятости по возрастам и этносам; рассматривайте каждый вывод как слабый сигнал, а не как истину.
